# README - what is in this folder

What this file is: a one-page map of `reuse_trials/gravel/`, the GRAVEL reuse trial (the question: how much of the shared layered slate recipe can make
another surface?). The full report is **`notes - gravel reuse trial.md`** (start there; section 11 lists every file); the short structured answer
is `trial_result.json`; the pictures to look at are `sheet_gravel.jpg`, `final_seed_sets.jpg`, `repeat_2x2_gravel.jpg`, `ladder_strip.jpg` and `maps_seeds_1.jpg`.

Files that are written by the project's own tools and so carry no note inside: `final/*/score.json` (from `lib/texture_compare.py`), the `log.txt`,
`final_bake.log` and `checks_run.log` files (Blender's own output), and all pictures (`.png`, `.jpg`). Every script (`.py`, `.sh`) and every file I wrote by hand
has a plain note at its top.

Folders: `final/` (the three final tiles and the COMBINE-rule height), `checks/` (proof tests), `ladder/` (what each layer adds), `rounds/` (the tuning record),
`look/` (the reference and the earlier tile, looked at once), `baseline_sample_01/` (the earlier recipe's first tile and its score).
