# Changes made to the layer files during integration (every one listed, newest last)

| # | file | change | why |
|---|---|---|---|
| 1 | layers/colour_and_fade.py | new control `mottle_tallness` (socket `Mottle Tallness`, default 2.2 = the old fixed value, range 0.5 to 6) | the flat patches inside a slate ran the whole slate height, so slates looked like corrugated sheets of stripes; the reference has strokes that stop part way. Default is unchanged so nothing else moves. |
| 2 | layers/combine.py | new control `tone_blend` (socket `Tone Blend`, default 0 = old behaviour, range 0 to 1): mixes the real relief with a height made from the finished colour's brightness (the reference's own formula, 2.5 x (brightness - 9.5)) | the reference height maps were made from the colour, ours is real relief (chips sunk); the "same kind" height measures reward the colour-made height. One honest knob lets a person choose. |
| 3 | layers/moss.py | new controls `rim_opacity` and `core_opacity` (sockets `Rim Opacity`, `Core Opacity`, both default 1 = solid, range 0 to 1). The moss MASK (not its height or roughness) is multiplied by an opacity that runs from `rim_opacity` at the rim of a clump to `core_opacity` once the dot is about 0.45 growth-strength units inside it | look-fixes round 2. The look checker found the moss reads as small crisp khaki flakes, like peeling paint, instead of the reference's soft olive wash that lets the slate streaks show through. A see-through rim gives a soft edge and a see-through core lets the streaks through. Defaults are 1, so with the controls at their defaults the picture is bit for bit the old one (checked at 384 dots: colour, height and roughness identical). |
| 4 | layers/moss.py | new control `side_clearance` (socket `Side Clearance`, default 0 = off, range 0 to 0.05 tile units): moss growth is pushed down near the side joints of a slate, fading out over this distance | look-fixes round 2, problem 11. Moss that reached a side joint was cut off in a straight line along the joint (14.5 % of the checker's moss dots within 14 dots of a side joint, 6.5 % in the reference); no setting could fix that. With 0.012 (15 dots) the same measure gives 6.1 % on a 900-dot test bake. The `gt(...)` switch makes it exactly nothing at 0. |
| 5 | layers/moss.py | new control `fleck_amount` (socket `Fleck Amount`, default 1 = as before, range 0 to 1.5): scales the small light and dark flecks inside the moss, which were a fixed amount before | look-fixes round 2. The flecks made the inside of the moss much busier than the reference (steepest-edge measure inside the moss 17.9 against 7.1). 0.5 in the default tile. |
| 6 | layers/outline_and_shadow.py | new controls `joint_texture` (socket `Joint Texture`, default 0 = flat black as before, range 0 to 1.5) and `joint_texture_size` (default 600 mottles across one tile, range 100 to 1200): the black of the joints is multiplied by a fine seamless noise | look-fixes round 2, problem 5 (relief). The reference's joints are faintly mottled (brightness spread 2.8 inside the black core), ours were perfectly flat (0.5), so the relief, which follows the colour, was flat in the joints too. 0.5 at the default size 600 gives a spread of 2.4 on a 900-dot test bake but looked like grit at 1:1 in a 1254 bake, so the default tile uses 0.35 at size 150. |

The old versions of the two files are kept in `look_fixes/round2/layer_files_before_round2/`.

## Independence test re-run for the two changed layers (look-fixes round 2, 20 October)

Why only these two layers: only `moss.py` and `outline_and_shadow.py` changed. How: `look_fixes/independence_two_layers_bake.py` (one Blender run) and `look_fixes/independence_two_layers_analysis.py` (plain Python, which reuses the counting functions of `tests/independence_full.py`). Same rules as the earlier full test: every layer is switched off (Amount 0) and given a new seed (Seed + 1), at 384 dots, with the settings of the new default tile; a dot counts as changed when the colour differs by more than 1/255, the height by more than 0.0005 or the roughness by more than 0.004.

The other layers' own masks (colour_and_fade, damage, moss, outline_and_shadow, piece ids) did not change at all, inside or outside, when moss or outline_and_shadow was switched off or re-seeded (every "outside" number is 0.0; the full table is `look_fixes/round2/independence/independence_two_layers_table.md`). So both changed layers are still independent. Not re-run: the half-tile shift test (the new controls use the same slate coordinates and seamless noise as before, and the finished tile's seam score is checked in the scores) and the independence of the unchanged layers (their files did not change).

Check that the new controls do nothing at their defaults: the same recipe (settings as they were after round 1) baked at 384 dots with the old files and with the new files gives identical colour, height and roughness pictures (maximum difference 0 in all three).
