# Examples (records)

What this folder is: pictures and notes from the plugin's earlier versions (0.2 to 0.5, October and November 2026), kept as a record of what the retired dressing, look stage and blind judge did. Their code was deleted from the plugin in 0.6.0 (see the plugin's README, "What was retired, and why"); the commands in these notes no longer run. It stays in the repository's history.

| Folder | What it records |
|---|---|
| `lane-blockout/` | a grey-box lane dressed by its object names, rounds 1 to 6 |
| `coal-mine/` | the look stage dropped onto a place built by someone else |
| `scanned-surfaces/` | code-made against photographed surfaces |
| `bach-on-the-beach/` | the shore dressing on a beach place |
| `tea-house-lessons/` | brass, copper, china and window joinery |

## Traps

- None of these commands run in 0.6.0; build a place with the brief kit (`../brief/`) instead.
