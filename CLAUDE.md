# Notes for Claude in this repository

What this file is: standing rules from the person who owns this project, for every session and every helper.

- **Every new set updates the plugin.** The person's words (23 October 2026): "Also for future reference, every new set that uses different tools
  needs to update the plugin." The plugin is `plugins/explainer-film`. When a place, set or props built here (a film set or a test scene) uses a tool,
  technique, material source or lesson the plugin does not carry, adding it to the plugin is part of that set's job. Do it before calling the set finished,
  and check it like the rest of the plugin: its tests, and a fresh checker.
- **The plugin must carry the techniques itself.** A model given only the plugin and a plain request should use normal maps, displacement, dirt,
  grime, weeds, weathering, damage and the rest without being told (decision 45 in `austerity-explainer/project-notes/Decisions.md`).
- **Decisions and rules with the person's exact words** are in `austerity-explainer/project-notes/Decisions.md`; the texture and place work's story is
  `procedural-textures/Procedural textures - project story.md`.
