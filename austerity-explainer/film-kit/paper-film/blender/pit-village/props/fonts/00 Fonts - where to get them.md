# Fonts - where to get them

The lettering on the scripted props (the coal sacks' stencils, the colliery's name board and the
lock-out notice) is drawn by `paint_prop_pictures.py` with these free fonts. The font files are not
kept in this repository because they are other people's work; their licence texts are here.

Put the .ttf files in this folder before running `paint_prop_pictures.py`:

| File | Font | Where | Licence |
|---|---|---|---|
| Ultra-Regular.ttf | Ultra | Google Fonts (fonts.google.com/specimen/Ultra) | Apache 2.0 |
| OldStandard-Regular.ttf, OldStandard-Bold.ttf, OldStandard-Italic.ttf | Old Standard TT | Google Fonts (fonts.google.com/specimen/Old+Standard+TT) | SIL Open Font Licence |
| AbrilFatface-Regular.ttf | Abril Fatface | Google Fonts (fonts.google.com/specimen/Abril+Fatface) | SIL Open Font Licence |
| AlfaSlabOne-Regular.ttf | Alfa Slab One | Google Fonts (fonts.google.com/specimen/Alfa+Slab+One) | SIL Open Font Licence |

The finished props (`assets/models/pit-village/props/*.glb`) already carry the lettering as pictures,
so the fonts are only needed to change the wording.
