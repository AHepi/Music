Japanese rebuild_06/final07 is substantially improved but **does not match the
requested visual target**. Eighteen live Geometry Nodes modifiers do not make the
whole scene parametric. Original references, generated design targets, flat
material assets, actual rendered output and the user’s judgment remain distinct.
The earlier Japanese critic completion was superseded by user feedback and is not
restored by these technical results.

- Pine: authored major wood, guides and profile hierarchy; live secondary shoots
  and needles. More fine needles do not replace designed crown lobes.
- Roof: authored course guides; live spacing, instance length, profile selection
  and settlement. Real lips/undersides, lapping and four-face upslope orientation
  matter more than random tile colour or tiny chips.
- Landscape: fixed masks with live height/scatter settings. Changing Bank Height
  does **not** reseat static rocks, paths/landings or major trees. Baseline support
  is not valid for every setting. Expand hard path exclusions by the maximum scaled
  prototype footprint; center-only density masks can put foliage through bridges.

Three representative control hashes reproduce, restore and reopen. They do not
prove all 18 modifiers, full topology/UV/material/prototype identity or whole-scene
pixel identity. Original QA helpers contain workspace paths; runtime rebuild
modules are relocation-aware. Do not call the whole source kit uniformly portable.

## Geometry Nodes field and API lessons

On the installed Blender 5.1.2, Resample Curve uses its Mode input with the titlecase
`Length` value. Capture/store Spline Parameter on the curve domain before Curve to
Points when it will drive tip selection. Explicitly connect Radius to Curve to
Mesh Scale. A nonempty branch mesh or connected graph can still produce zero
foliage or ignored radius. Check actual evaluated counts, dimensions and effects.

The optional **Roof Course Lab** is a separate experimental source/data companion.
Manually append its root collection to a new metre-scale test scene. It contains
six actual thick profiles and four fixed course orientations, with width, length,
settlement and seed controls. It is not installed or executed by the extension.
Existing selection-preview exclusions are unchanged. Read its own README and
measured evidence before using it. There is no automatic production scene wrapper.

## Pigment and water

Generated flat pigment maps carry prompts, dimensions and mapping provenance.
They are not generated target images projected onto a scene. Actual plaster uses
normalized Generated coordinates with BOX projection; physical mark scale varies
with wall bounds. Explicit material-local UVs can preserve grain direction, but
changes must be isolated from unselected shared users and tested by material family.

The street water diagnosis found 78 mm opaque sheets above 27–36 mm cobble relief.
Selected B uses 30.5 mm textured-edge film with Fresnel-weighted reflection and
transparent transmission; it has no refractive depth or volume absorption.
Measure elevation and actual reflection coverage before blanket gloss or fog.
Its 29-sheet result is a scene-specific study, not a universal water preset.

## Coverage, intersections and review

State intended semantic families before targeting. Compare expected, selected,
changed and excluded families using actual saved source labels and dependencies;
operator names and object counts alone cannot show coverage. Preserve inherited
intersections as inherited until independently measured. New hardware must be
checked against inherited as well as new geometry. Distinguish intentional lapping
or structural contact from exposed coplanar competition and unintended penetration.
A closed prototype also needs outward-winding/signed-volume checks; edge incidence
alone missed the provisional mine plate failure.

Final D barrel evidence preserves C’s eight-control geometry while changing only
three body translations, with fresh finite support/nearby clearance. The initial
penetration is a rendered observation, not a fabricated baseline collision audit.
Corrected mine source hardware has 50 positive-volume closed shells; all 246 GN
fasteners are finite and the tested Scale edit restores exact instance matrices.
All 562 rebound originals preserve raw positions/topology/smoothing/transforms.
The initial two labelled coal loads missed 88 additional semantic-family meshes;
final coverage is 90. These are bounded technical results, not universal selection
rules, arbitrary-control contact guarantees or whole-image art acceptance. Keep
failed diagnostics, untested controls and unresolved user feedback visible.
