## Mechanisms adapted

The small `response.py` adapter derives its core pattern from the project's
frozen schema-3 `painterly_style.py`: preserve the original shader, feed the same
albedo to a Cycles diffuse/toon branch, retain authored normals, optionally add a
bounded asset-attached normal perturbation and blend explicitly. Stored rest
coordinates are authored only on private mesh copies.

  `cca7486660f1b200d2dd066cda69344466147e56f5612f8b2b02f07b571b2cb1`.

  `5f4a6631b879cc831a83ea8945cae6ed0099c472d4c81f696668fdabae47ae87`.

These paths describe source lineage within the working project; the extension
does not import or depend on those files. It does not vendor their scene-wide
orchestration, exact production family values, floor layout masks, cloth flow,
sky mapping, volume envelope, camera setup or compositor reconstruction. The
implemented light controls are standard per-light energy/color multipliers,
tested independently in this package. Geometry changes use Blender's unapplied
Bevel modifier, with new bounded preflight and copy-on-write transaction code.

This adapter is a new, smaller implementation. The production core's historical
18 arithmetic/control cases do not automatically transfer to it. Only the
new package tests named in TEST_REPORT.md are claimed. The original numerical
limitations, including failed strict independent-build identity, are not erased.
