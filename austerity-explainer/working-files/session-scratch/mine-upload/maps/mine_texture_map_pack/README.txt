Mine texture map pack (best-effort)

Contents for each texture:
- *_basecolor.png: material/base-color/albedo texture
- *_normal.png: tangent-space normal map derived from the base color
- *_displacement.png: grayscale displacement/height map derived from the base color

Textures included:
- ground_mud
- brick_wall
- rusted_metal
- aged_wood
- roof_slate
- gravel_ballast
