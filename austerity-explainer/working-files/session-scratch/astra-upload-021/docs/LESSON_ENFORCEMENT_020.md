# Lessons with executable consequences

| Lesson | Runtime consequence | Separating witness |
|---|---|---|
| Source identity survives names/reopen | Persistent ID pointers, private receiver data, exact slot modes; conservative restore refusal | Renamed sources/cutters, multi-slot DATA/OBJECT/empty slots, shared materials, source tamper and reopen |
| Seed means reproducibility | SHA-derived local RNG, stable candidate IDs, explicit private shader seed, fixed object-pointer bank order | Same seed after rename/pose/list reorder; different seed and return; recreation after swapped source names |
| Coarse masks can lie | Triangle/rectangle/capsule intersection freezes whole source polygons, not only vertices inside masks | Four-vertex quad with tiny protected center; fine grid; diagonal corridor boundaries; outside relief control |
| Visible relief can be masked away | Peak relief and conservative suppression are reported; layout masks explicit | Coarse/fine controls and fresh fixed-camera workshop comparison |
| Scatter center hit is insufficient | Evaluated source bounds, eight perimeter probes, tangent-plane residual, loop triangles, source origin guard | Oversized/offset source, gentle plane versus sharp bank break, receiving-surface edit warning |
| Field context changes after Set Position | Ray origin combines original XY with a fixed high Z | Native instance count, live density, save/reopen and actual courtyard adapter |
| Moss needs body and correct winding | Closed low clipped body; top-face and manifold checks; native source downward-face warning | Body topology check; failed square-grid contour render retained; current hero/near review |
| Material-specific form matters | Timber check, stone fissure, ceramic edge notch; explicit substrate | Evaluated Boolean geometry and transform-bound cutters per family |
| Shared names/images are not identities | Private shader group and private atlas Image; source originals retained | Poisoned same-name group and existing Non-Color/unpacked atlas remain untouched |
| Path JSON may contain different widths | Preserve every width unless explicit all-width override | Heterogeneous [1.25, 0.23] round-trip plus deliberate override |
| Structural frames precede style variation | Straight run stays level/fixed-end; courtyard bridge tangent frame separate from twist | Courtyard bearing/joint audit; no generalized curved-path claim |
| Registration is not visual success | Reports carry `art_acceptance: not_determined`; frustum/pixel estimates warn only | Independent mechanical tests and separate actual render review |

Finite support tests remain finite. They neither certify structural safety nor continuously inspect every new deformation. Semantic masks are authored eligibility fields, not biological simulation. Tests are named witnesses with explicit rivals, not an aggregate aesthetic score.
